# Журнал використання ШІ (AI Usage Log)

## 1. Інструменти
- **Назва/Модель:** ChatGPT / Claude 3.5 Sonnet / Gemini
- **Дати використання:** Жовтень 2026

## 2. Журнал використання
- **Етап:** Проектування конфігурації TLS Mosquitto.
- **Мета:** Створення захищеного файлу mosquitto.conf з підтримкою сертифікатів та ACL.
- **Промпт:** "Як правильно налаштувати TLS 8883 та ACL у Mosquitto v2?"
- **Використано:** Приклади директив ACL та мережевих listener.
- **Змінено та перевірено:** Налаштовано шляхи до сертифікатів, згенерованих власним скриптом, перевірено підключення через mqtt-cli.

## 3. Промпти дослівно
1. *"Створи Python-скрипт з paho-mqtt, який публікує симульовані дані за схемою плавної синусоїди з додаванням шуму та підтримує LWT."*
2. *"Напиши правила openHAB DSL для перевірки потужності та авто-вимкнення обігрівача при перевантаженні."*
3. *"Як згенерувати CA та сертифікат сервера за допомогою openssl в одному Bash скрипті?"*

## 4. Помилки ШІ
- **Помилка:** ШІ запропонував застарілий синтаксис `mqtt.cfg` для openHAB v1 замість створення `mqtt.things` для openHAB 3/4.
- **Виявлення:** openHAB 4 не зчитував конфігурацію брокера.
- **Виправлення:** Вручну переписано у формат DSL `.things` з оголошенням `Bridge mqtt:broker`.

## 5. Власний внесок
- Написання структури Docker Compose та зв'язок сервісів у єдину мережу.
- Тестування сценаріїв за допомогою аргументів `--scenario`.
- Налаштування Sitemap та UI графіків openHAB.

## 6. Висновок
Під час виконання роботи я засвоїв принципи побудови захищених IoT-систем із використанням TLS/ACL та інтеграції автоматизацій у openHAB. Робота з ШІ прискорила написання boilerplate-коду, однак вимагала власного розуміння архітектури для виправлення помилок сумісності. Я зможу самостійно відтворити таку систему без допомоги ШІ.
